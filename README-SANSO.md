# ติดตั้งคำถามและร่างประวัติสินค้าใน SANSO

1. แตก ZIP แล้วอัปโหลด `index.html`, โฟลเดอร์ `api` และ `lib` ไปยังหน้าแรกของ repository `johngrabana-cloud/san` ให้ตรงตามโครงสร้างใน ZIP อย่าอัปโหลด ZIP ทั้งก้อนเป็นไฟล์เว็บ
2. ให้ `api/product-history/scan.mjs`, `api/product-history/status.mjs` และ `package.json` ที่มี `@neondatabase/serverless` จากโปรเจกต์เดิมอยู่ด้วย โค้ดอ่าน `DATABASE_URL` และ `GEMINI_API_KEY` จาก Vercel
3. รอ Deploy บน Vercel จนขึ้น Ready แล้วเปิดเว็บจากโดเมน Vercel เข้าแอดมิน → ตั้งค่า Gemini API → ทดสอบการเชื่อมต่อ → เลือก “เรียก Backend จริง” → บันทึกและใช้ Prompt นี้
4. เพิ่มสินค้าอ้างอิงใน Neon และเพิ่ม SHA-256 ของไฟล์ภาพที่ฟอร์มส่งจริงลงใน `reference_images` ให้ผูกกับรายการเดียวกัน ถ้าหน้าเว็บย่อหรือแปลงภาพ ให้คำนวณจากไบต์หลังแปลง ใช้รูปอ้างอิงเพียง 1 รูปก่อนทดสอบ และใส่ `source_url` เป็นแหล่งข้อมูลจริงที่เปิดได้
5. จากเบราว์เซอร์เดียวกัน สลับไปบัญชีร้านค้า เลือกสินค้ามือสอง → “ตอบคำถามประวัติ” หรือแก้ไขแล้วกดลงสินค้า เมื่อจับคู่รูปสำเร็จ หน้าต่างขึ้น “คำถามจาก Gemini” หากจับคู่ไม่สำเร็จหรือ API ใช้ไม่ได้ จะมีคำถามมาตรฐานให้บันทึกคำตอบ
6. หลังบันทึกคำตอบ รอให้ระบบเตรียมร่าง แล้วกด “ยืนยันภาพและรายละเอียด” ของสินค้ารายการนั้น ตรวจร่างและส่งแอดมินตามขั้นตอนเดิม

การทดสอบนี้ใช้การตั้งค่าและร่างเรื่องราวในเบราว์เซอร์เดียวกัน ผลสแกนผูกกับคุกกี้ชั่วคราว 15 นาทีสำหรับระบบทดลอง ควรใช้ระบบยืนยันตัวตนร้านค้าฝั่งเซิร์ฟเวอร์ก่อนเปิดให้ผู้ขายจริงใช้ API ที่เรียก Gemini

ระบบส่งรูปจริงไปให้ Gemini หลังตรวจว่าเป็นรูปที่อยู่ในรายการอ้างอิง และส่งร่างพร้อมรูปจริงให้ตรวจ ตัวอย่างนี้ให้แอดมินตรวจประวัติก่อนเผยแพร่ และไม่ได้เปิดการค้นเว็บอัตโนมัติ
